Updated standards. Existing procedures. One difficult question: what changed, and did we cover it?

PHMSA incorporated the second editions of API RP 1170 and API RP 1171 into 49 CFR Part 192, effective January 1, 2026. For operators, the work extends beyond reading the standards. Applicable requirements must be traced into procedures, responsibilities, records, and evidence.

API RP 1170

Design and operation of solution-mined salt caverns used for natural gas storage.

API RP 1171

Functional integrity of natural gas storage in depleted hydrocarbon and aquifer reservoirs.

A cited answer can still miss the record that matters.

General-purpose search and RAG answer from the material they retrieve. A citation shows that an answer has support, but it does not prove that the complete evidence set was considered.

General document AI

  • Retrieves passages related to the question
  • Produces an answer from what it found
  • Cites the returned text
  • May not reveal that another required record was never retrieved

Kataba UGS evidence workflow

  • Begins with the evidence expected for the UGS question
  • Accounts for each required procedure, limit, record, response, and version
  • Separately identifies present, missing, stale, and conflicting evidence
  • Returns INSUFFICIENT EVIDENCE when the available record cannot support a clean conclusion
  • Routes the result to the responsible expert for review

A citation demonstrates support. Kataba tests whether the available evidence is complete enough for an expert to rely on.

Frequently asked questions

What is the difference between API RP 1170 and API RP 1171?+

API RP 1170 addresses the design and operation of solution-mined salt caverns used for natural gas storage. API RP 1171 addresses the functional integrity of natural gas storage in depleted hydrocarbon and aquifer reservoirs. Both were incorporated into 49 CFR Part 192 by PHMSA, effective January 1, 2026.

How does Kataba support procedure gap analysis?+

Kataba connects each applicable requirement or review question to your operating procedures, document versions, and supporting records, then separately classifies present, missing, stale, and conflicting evidence so a reviewer can see exactly where a procedure is supported and where it is not.

Can Kataba work with scanned and handwritten records?+

Yes. Kataba uses OCR, table extraction, and handwriting recognition to make scanned reports, historical well files, forms, and maps searchable. Low-confidence extractions stay linked to the original page and are flagged for human verification.

Can Kataba connect to databases and existing repositories?+

Database and repository connections are scoped per engagement based on the operator's systems and requirements. During a bounded POC, Kataba typically works from an approved export or a defined access point agreed with the operator in advance.

Does Kataba determine whether an operator is compliant?+

No. Kataba organizes and tests the available evidence, identifies gaps and conflicts, and supports expert review. Regulatory and engineering determinations remain with the operator’s authorized personnel and advisors.

Can Kataba be deployed on premises?+

Deployment options, including on-premises or private-cloud configurations, are discussed and scoped during the POC to align with the operator's IT and security requirements.
